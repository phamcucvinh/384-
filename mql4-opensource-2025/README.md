# MQL4 Open Source Collection (2025 Updated)

2025년 9월 1일 이후 업데이트된 MQL4 오픈소스 프로젝트 모음

## 📚 프로젝트 목록

### 1. EABTCGrid
**업데이트**: 2025-09-21  
**설명**: 비트코인 그리드 트레이딩 EA v5.1
- ATR 기반 동적 그리드 간격
- EMA 크로스오버 전략
- 멀티타임프레임 지원 (M5/M15/H1/H4)
- 자동 리스크 관리

### 2. Three-Line-Break
**업데이트**: 2025-09-21  
**설명**: 3라인 브레이크 차트 인디케이터
- 가격 움직임 시각화
- 트렌드 전환 신호
- 커스터마이징 가능

### 3. ma-cross-ea
**업데이트**: 2025-09-08  
**설명**: 이동평균 크로스오버 EA
- 단순하고 효과적인 전략
- 자동 매매 시스템

### 4. mql4-template
**업데이트**: 2025-09-08  
**설명**: MQL4 EA 개발 템플릿
- 기본 EA 구조
- 코드 재사용 가능

## 📄 파일 형식

- `.mq4` - MQL4 소스 코드
- `.mqh` - MQL4 헤더 파일
- `.mq5` - MQL5 소스 코드

## 🎯 사용 방법

1. MetaTrader 4/5 설치
2. 해당 프로젝트 폴더의 파일을 `MQL4/Experts/` 또는 `MQL4/Indicators/`로 복사
3. MetaEditor에서 컴파일
4. 차트에 적용

## ⚠️ 면책 조항
